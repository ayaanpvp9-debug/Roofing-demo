# Oak & Iron Roofing

A premium, responsive one-page roofing company website demo built with React, Vite, Framer Motion, and custom CSS.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Demo notes

- Estimate form submissions are client-side only. The confirmation screen makes clear that no message is sent or stored.
- Testimonials and project imagery are labeled as demo/sample content; they are not represented as verified client work or reviews.
- Phone and email details are intentional placeholders.
