# ROOFCRAFT

A fictional architectural roofing studio, built with React, Vite, GSAP ScrollTrigger, Framer Motion, and Lenis.

## Run

```sh
npm install
npm run dev
```

`npm run build` creates the production site in `dist`.

## Experience

- Parallax cinematic hero and masked typography entrance
- Scroll-triggered editorial reveals and animated counters
- Interactive six-service showcase
- Horizontal, scroll-snap project portfolio with detail dialogs
- Keyboard-accessible before/after range comparison
- Animated testimonial carousel
- Responsive navigation and validated demo estimate form
- Reduced-motion support and touch-friendly layouts

All brand details, statistics, projects, and testimonials are fictional. The estimate form is client-side only and does not transmit or store personal information. The comparison uses the same photograph with a simulated weathered treatment, explicitly labeled in the interface. Photography is loaded from Unsplash; fonts are loaded from Google Fonts, requiring internet connectivity.
